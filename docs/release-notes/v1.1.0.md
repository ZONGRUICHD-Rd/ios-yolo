AprilTag 追踪稳定性改进，并修正坐标轴方向。

### 变化
- **Z 轴改为垂直指出 Tag（朝向相机）**。为保持右手系，Y 轴改为向上；X 仍沿上边向右，原点仍在 Tag 左上角。与 OpenCV/ArUco 的标记坐标系方向一致。
- **解决坐标轴来回翻转**：Tag 较小或几乎正对相机时，两个位姿解的误差几乎一样，以前每帧只取误差最小的那个，Z 轴会来回翻。现在两个解都保留，并按以下顺序选择：
  - **同一平面上 ≥3 个 Tag 时**（比如那张 A4）：用各 Tag 中心拟合出纸面，选与纸面方向一致的解。思路来自 Ch'ng et al.，ICRA 2020。
  - **其余情况**：沿用离上一帧最近的解，另一个解持续明显更好才切换。做法与 ArUco 的 `MarkerPoseTracker` 相同。
- **减少抖动**：对位置和旋转做 One Euro 滤波（Casiez et al.，CHI 2012），静止时更稳，快速移动时仍然跟手。AprilTag 面板新增"平滑"滑块（灵敏 / 均衡 / 稳定）。

### 仿真结果
把 tag36h11 A4 按已知位姿渲染到模拟的 iPhone 相机、加噪声，与真值对比：
- 1.8–2.4 m 远处，选错位姿解的比例从 25–34% 降到 1–10%。
- 静止时位置抖动降低 6–10 倍；代价是移动时约 1–2 mm 的滞后。

真实视频里的运动模糊和果冻效应（rolling shutter）在仿真里没有模拟，新的跟踪算法也还没在真机上测过，欢迎反馈。
