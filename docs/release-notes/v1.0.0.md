iPhone 上实时运行 YOLO26 与 AprilTag 追踪的首个版本。

### 功能
- **YOLO26 实时检测**：后置摄像头 1080p@60fps，内置 `yolo26n`、`yolo26s`（Core ML FP16，NMS-free 端到端输出）
- **计算单元切换**：NPU（`.cpuAndNeuralEngine`）/ GPU（`.cpuAndGPU`）/ CPU（`.cpuOnly`）/ Auto（`.all`）
- **跑分对比**：在 NPU / GPU / CPU 上各测 50 次推理，并用 `MLComputePlan` 显示各芯片实际承担的算子比例
- **AprilTag（tag36h11）**：画框、显示 ID，按 ID 跨帧追踪并画出轨迹；以每个 Tag 左上角为原点建立右手坐标系（X 向右、Y 向下、Z 指入 Tag），实时显示该点在相机坐标系下的位置（cm）和距离
- 检测模式可选 YOLO / AprilTag / 同时

### 安装
`YOLOApp-unsigned.ipa` **未签名**，需要先用 Sideloadly、AltStore、SideStore、TrollStore 或自己的证书重签再安装。需要 iOS 17 及以上，首次打开要授予相机权限。

### 注意
- 还没有在真机上做过完整测试，欢迎反馈问题。
- AprilTag 的距离以 App 里设置的 **Tag 边长**为准（外圈黑色正方形，不含白边，默认 6.9 cm），请用尺子量过后再填。
- 打印 AprilTag 官方 PNG 时，把"图案方向"切到"官方图"，否则原点会落在对角。
- 首次切到 NPU 时系统要为 Neural Engine 编译模型，会卡几秒。
